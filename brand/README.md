## 品牌規範

- **主色**：暖白底 `#FAF8F5`、文字 `#1A1A1A`
- **品牌色**：藍紫 `#4F46B5`（使用 ≤5%）
- **輔助色**：`#6B655C`（次要文字）、`#E8E4DF`（分隔線/背景）
- **標題字體**：DM Serif Display
- **內文字體**：Inter
- **視覺風格**：Aesop/Apple 極簡高級質感，🚫 霓虹/發光/科技暗黑風

## 注意事項

- `k1-logo-transparent.png` 是網站 header/footer 使用的版本
- 所有衍生素材統一放 `exports/`，檔名用小寫 + 連字號
- 輸出解析度至少 2x（Retina ready）
